# Pothole Detection Using Computer Vision

## 1. Problem Statement

Potholes can create road hazards and contribute to vehicle damage.
Manual road inspection can be time-consuming.

This project demonstrates an image-processing approach for identifying
potential pothole regions in road images.

## 2. Objective

- Preprocess road images.
- Identify potential dark regions using adaptive thresholding.
- Extract candidate regions using contour analysis.
- Visualize candidate detections.
- Evaluate detections against manually annotated pothole boxes.

## 3. Dataset

No separate dataset is downloaded. Input images are provided by the
user. Ground-truth bounding boxes must be manually annotated.

See `dataset/README.md`.

## 4. Methodology

1. Load a road image.
2. Convert the image to grayscale.
3. Apply Gaussian blur and CLAHE.
4. Perform adaptive thresholding.
5. Apply morphological operations.
6. Extract contours and filter regions by size.
7. Draw bounding boxes around candidate regions.
8. Evaluate candidate boxes using IoU-based matching.

## 5. Tools and Libraries

- Python
- Google Colab
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 6. Results

The project generates:
- Preprocessed image
- Candidate mask
- Annotated detection image
- Candidate bounding-box CSV
- Evaluation CSV

Results must be generated by running the notebook.

## 7. Performance Evaluation

Precision, recall, and F1-score are calculated by matching predicted
bounding boxes with manually verified ground-truth boxes using an
IoU threshold of 0.50.

These metrics are meaningful only when the annotations are correct
and the evaluation includes representative images.

## 8. Limitations

- Dark road regions may be mistaken for potholes.
- Potholes may be missed under poor lighting.
- Fixed thresholding parameters may not work across all road surfaces.
- The method does not understand pothole depth or severity.
- A single image cannot establish general performance.

## 9. Conclusion

This project demonstrates a classical image-processing baseline
for pothole candidate detection. A dedicated pothole detection model,
more diverse annotated images, and extensive testing could improve
robustness.

## 10. How to Run

Open `Pothole_Detection.ipynb` in Google Colab and run the cells
in order. Upload a road image when prompted. Verify the candidate
regions and annotate actual potholes before interpreting evaluation
metrics.
