# Fruit Counting and Yield Estimation Using Computer Vision

## 1. Problem Statement

Manual fruit counting can be time-consuming. Computer vision can
assist in counting visible fruits and analyzing fruit images.

## 2. Objective

- Detect supported fruit categories.
- Count detected fruit instances.
- Measure visible bounding-box dimensions in pixels.
- Demonstrate a simple mass-estimation calculation.
- Evaluate count predictions against manually verified counts.

## 3. Dataset

This demonstration uses a user-provided fruit image. No separate
dataset is downloaded. See `dataset/README.md`.

## 4. Methodology

1. Load and preprocess the image.
2. Load a pretrained YOLOv8n model.
3. Detect supported fruit categories.
4. Count detected fruits.
5. Calculate bounding-box dimensions.
6. Estimate visible-fruit mass using stated average-mass assumptions.
7. Compare predicted counts against verified ground truth.

## 5. Tools and Libraries

- Python
- Google Colab
- Ultralytics YOLOv8
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 6. Results

The project generates fruit detections, count charts, size measurements,
estimated-mass tables, and evaluation CSV files.

Numerical results must be generated by running the notebook.

## 7. Performance Evaluation

MAE and RMSE compare predicted counts with manually verified counts.

Evaluation is meaningful only when the ground-truth counts are correct
and the test images represent the intended application.

## 8. Limitations

- Only supported fruit classes can be detected reliably.
- Overlapping and occluded fruits may be missed.
- Bounding-box dimensions are not physical dimensions.
- Estimated mass relies on assumed average fruit weights.
- A single image cannot establish total orchard yield.

## 9. Conclusion

This project demonstrates fruit detection, counting, visual size
analysis, and illustrative mass estimation. Reliable agricultural
yield prediction would require appropriate field images, calibrated
measurements, representative annotations, and measured fruit weights.

## 10. How to Run

Open `Fruit_Counting_Yield_Estimation.ipynb` in Google Colab.
Run the cells in order, upload a fruit image, and enter verified
ground-truth counts before interpreting evaluation results.
