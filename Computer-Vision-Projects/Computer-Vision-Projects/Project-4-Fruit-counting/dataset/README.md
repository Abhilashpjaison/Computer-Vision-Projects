# Dataset Information

## Data source

This project uses user-provided fruit images. No separate dataset
is downloaded.

## Input requirements

Images should clearly show the fruit categories supported by the
pretrained detection model.

## Pretrained model

The YOLOv8n model is loaded through Ultralytics. Its pretrained
weights are obtained automatically when needed.

The pretrained model is not a fruit-specific agricultural yield model.

## Ground truth

Actual visible fruit counts must be manually verified for evaluation.

## Limitations

The model may miss overlapping, small, occluded, or unsupported fruits.
