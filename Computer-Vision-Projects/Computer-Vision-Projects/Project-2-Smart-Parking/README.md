# Smart Parking Space Detection

## 1. Problem Statement

Finding available parking spaces manually can waste time and cause
unnecessary traffic within parking facilities.

This project demonstrates a computer vision approach for detecting
vehicles and estimating parking-space occupancy from an image.

## 2. Objective

- Detect common vehicle classes using a pretrained YOLOv8 model.
- Define individual parking-space regions.
- Estimate whether each defined space is occupied or available.
- Visualize the result using colored rectangles.
- Evaluate occupancy predictions using standard classification metrics.

## 3. Dataset

No separate parking dataset is downloaded for this demonstration.
The input is a user-provided parking-lot image.

Parking-space regions and ground-truth occupancy labels are manually
defined and must be verified against the image.

See `dataset/README.md`.

## 4. Methodology

1. Load the input parking image.
2. Load the pretrained YOLOv8n model.
3. Detect vehicle classes.
4. Define parking-space regions.
5. Calculate overlap between vehicle detections and parking regions.
6. Estimate occupancy from the overlap threshold.
7. Generate annotated images and occupancy summaries.
8. Evaluate predictions against manually verified ground-truth labels.

## 6. Results

The program generates:
- Vehicle detection output
- Parking occupancy visualization
- Parking status CSV
- Vehicle count CSV
- Occupancy summary chart
- Confusion matrix
- Classification metrics

Numerical results must be generated by running the notebook and
must not be entered as assumed values.

## 7. Performance Evaluation

The project calculates accuracy, precision, recall, and F1-score
by comparing predicted occupancy with manually verified labels.

These metrics are meaningful only when the ground-truth labels are
correct and the test examples include the classes being evaluated.

## 8. Limitations

- The parking spaces are manually defined.
- Vehicle detection may fail under unusual viewing angles,
  poor lighting, or occlusion.
- Vehicle overlap is only a baseline occupancy heuristic.
- One image cannot establish general performance.
- The pretrained model is not specifically trained for parking occupancy.

## 9. Conclusion

This project demonstrates a baseline computer vision pipeline for
vehicle detection and parking-space occupancy estimation. Further
work could include automatic parking-space localization, a dedicated
occupancy classifier, and evaluation on a larger labeled dataset.

## 10. How to Run

Open `Smart_Parking_Space_Detection.ipynb` in Google Colab and
run the cells in order. Upload a parking-lot image when prompted.

Adjust the parking-space coordinates and verify the ground-truth
labels before interpreting the evaluation metrics.
